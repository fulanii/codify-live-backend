# CodifyLive (Backend)

Backend for CodifyLive a real-time collaboration platform that lets users chat, call, and code together directly in the browser. Built with FastAPI, this project was developed entirely by me without AI, to demonstrate my backend engineering skills and showcase a production-style implementation with secure authentication, real-time collaboration APIs, and modern backend services that power the frontend client. This project will be fully deployed on AWS as part of my AWS Certified Solutions Architect – Associate preparation and hands-on cloud architecture practice.

Check-out [Frontend](https://github.com/fulanii/codify-live-frontend)
